## Install

1. **[Download Atlas-Pilot-Setup.exe](https://github.com/KiddyDevOfficial/atlas-pilot-releases/releases/download/setup/Atlas-Pilot-Setup.exe)**. That's the only file you need.
2. Run it. Windows may say *"Windows protected your PC"*, because Atlas Pilot isn't code-signed yet. Click **More info**, then **Run anyway**.
3. Atlas Pilot opens when setup finishes, and you'll find it on your desktop and in the Start menu. Create a space for your project folder, then install the Atlas Studio plugin from **Help**, **Install Studio Plugin**.

## Updates

You never download Atlas Pilot again. When there's a new version, Atlas Pilot shows **Update ready** in the status bar. Click it, then **Restart to update**, and you're on the new version. Your spaces and settings stay.

To check by hand: **Help**, **Check for Updates**.

## What it does

- **An IDE for Roblox scripts.** Tabs, breadcrumbs, Quick Open, find in scripts, problems and Luau completions, laid out like the editors you already know.
- **An AI agent that works in your place.** Pick the model and how hard it thinks, from quick answers to long multi-step jobs. It reads and writes your scripts, runs playtests, and every change it makes can be kept or reverted.
- **Two-way Studio sync.** The Atlas plugin keeps the scripts in Studio and the files in your project folder in sync, both ways, with no other sync tool needed.
- **A built-in terminal** for git, Rojo, or anything else you run.
- **Properties and UI preview.** Inspect and edit instance properties and preview your ScreenGuis without leaving the app.

## What you need

- Windows 10 or 11
- Roblox Studio
- An Anthropic or OpenAI-compatible API key for the agent

Only **Atlas-Pilot-Setup.exe**, from the button above. The other files on the [Releases](https://github.com/KiddyDevOfficial/atlas-pilot-releases/releases) page (`latest.json`, the versioned setup and its `.sig`) are what Atlas Pilot downloads by itself when it updates. You can ignore them.
